# БрендUa — оновлена версія

Додано перемикач світлої/темної теми на всіх сторінках із збереженням вибору в `localStorage`.
На головній сторінці додано відео на Hero-банер: на ПК — при наведенні; на телефоні — за кнопкою. Фото залишається запасним фоном.

**Відеофайли потрібно скопіювати** з вашої папки до `assets/video/` під назвами `video_content.webm` та `video_content.mp4`. Їх немає в ZIP-архіві, який був завантажений у чат. Інструкція також у `assets/video/README.txt`.

Після додавання відео завантажте **всю** структуру на GitHub/Vercel. Для локальної перевірки використовуйте Live Server або `python -m http.server 8000` (відкрити `http://localhost:8000`).
